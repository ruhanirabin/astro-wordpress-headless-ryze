# Security Policy

## Supported Versions

This project is maintained on the `main` branch. Security fixes are applied there.

## Reporting a Vulnerability

Please report security issues **privately**.

1. [Contact Here](https://www.ruhanirabin.com/contact/)
2. Include:
   - A clear description of the issue
   - Steps to reproduce
   - Potential impact
   - Any suggested fix or mitigation

We’ll acknowledge your report within **7 days** and provide an estimated timeline for a fix after triage.

## Disclosure Policy

We follow coordinated disclosure:

- We’ll work with you to validate and fix the issue.
- We’ll agree on a public disclosure timeline.
- We’ll credit you in the release notes if you want.
